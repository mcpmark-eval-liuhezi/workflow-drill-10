# Contributing Guide

Thanks for your interest in contributing! This is a throwaway sandbox repo for a team contribution-workflow demo, so feel free to experiment freely.

## How to propose a change

1. Fork the repository to your own account.
2. Create a new branch for your work: `git checkout -b <short-description>`.
3. Make your changes and commit them with clear, descriptive messages.
4. Open a pull request against `main` and link it to this issue.

## What the guide should cover

- How to propose changes (fork, branch, pull request)
- How to find a good starting issue (look for `good-first-issue`)
- How to write a clear pull request description
- What the code review process looks like
- How issues should be sized and linked to pull requests when a change is made

## Code of conduct

Be respectful, keep pull requests small and focused, and leave kind comments during review.
